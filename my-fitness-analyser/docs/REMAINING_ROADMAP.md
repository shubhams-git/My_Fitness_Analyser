# Remaining release work

8 November 2026. Five major workstreams after F11; this is an engineering grouping,
not a claim that the application can never grow beyond five tasks.

1. Reviewed NRC/Strava screenshot publication: member review of extracted fields,
   source evidence, date/precision checks and canonical duplicate resolution.
2. Longitudinal coaching: comparable run trends plus deliberate strength/body
   context, evidence-linked visualizations and separately reviewed AI input scope.
3. Second-member onboarding and provider connections: invite Saurav when his email
   is supplied; encrypted per-member Garmin authorization rather than owner's key.
4. Sync reliability: resumable scheduled sync, freshness/failure states and bounded
   retries within the free hosting/provider constraints.
5. Release hardening: actual iPhone Safari/touch and real-user logging timing,
   accessibility/performance checks, and a reviewed complete-library v2 restore flow.

Training-plan editor, exercise sets/repetitions and social features are future
options outside this first-release completion count. F11 delivers manual strength
sessions and the distinct check-in; it does not yet add them to AI briefings.
